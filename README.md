# 💕 Valentine's Day App

A sweet, interactive React app to surprise your special someone on Valentine's Day.

## What's inside

- **Modern UI** — Dark romantic theme with rose & gold accents, glassmorphism card
- **Floating hearts** — Gentle background animation
- **Openable love letter** — Tap to reveal a short message
- **“Will you be my Valentine?”** — Yes triggers confetti and a success screen; the “No” button moves away on hover and eventually turns into “Okay maybe... 👀”
- **Smooth animations** — Framer Motion for scroll and micro-interactions

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
